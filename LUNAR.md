# LUNAR.md — Project Guide for Lunar 🌙

> LUNAR reads this file on every orbit. Keep it short and true.

## What this is
- LUNAR: Moonlit Terminal AI Coding Assistant (Node 18+, single file, zero dependencies).

## Commands
- Dev & Help: `node lunar.mjs --help`
- Diagnostics: `node lunar.mjs doctor`
- Interactive Orbit: `node lunar.mjs`
- One-Shot Task: `node lunar.mjs "task"`
- Setup Wizard: `node lunar.mjs setup`

## Map
- `lunar.mjs` — The complete, self-contained single-file agent (aesthetics, LLM client, tools, REPL, and subcommands).
- `lunar` / `lunar.cmd` — Zero-friction shell and Windows batch launchers.

## Rules
- Never print API keys or credentials.
- Prefer surgical code edits; read context before modifying.
- Always verify changes with tools or tests.
