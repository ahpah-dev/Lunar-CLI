PURE PERFORMANCE

Engineered Without Compromise

Built from the ground up to eliminate dependency rot, bloated memory footprints, and unstable terminal abstractions.

🪶

Zero npm Dependencies

Powered solely by the Node.js 18+ standard library (fs, path, readline, child_process, crypto, sqlite). No 300MB node_modules folder, no supply-chain vulnerabilities, zero installation wait.

⚡

Surgical Atomic Edits

Instead of rewriting entire files, Lunar computes precise contiguous character offsets. It previews unified colored diffs and applies atomic replacements without truncating or mutating unrelated code.

🪐

Multi-Provider Orbit

Seamlessly switch between OpenRouter (Nemotron, Claude, GPT, Apodex), 100% offline local Ollama instances, 9Router local gateways, or any custom OpenAI-compatible API endpoints.

🛡️

Interactive Safety Shield

Four granular permission modes: ask (interactive diff approvals), auto (auto-apply edits with command confirmations), plan (read-only analysis), and yolo (autonomous flow).

🌕

Astronomical Precision

Calculates real-world synodic moon cycles, illumination percentages, and celestial RGB terminal gradients. Beautiful animated orbit spinners keep you informed during generation.

↩️

One-Click Time Machine

Every file write and surgical edit automatically registers an undo checkpoint in .lunar/backups/. Instantly rollback any action with the /undo command.

ORBIT INITIALIZATION

Get Running in 30 Seconds

Zero installation friction. Run directly with Node.js 18+ or install globally.

1

Clone the Repository

Grab the single file repository directly from GitHub:

git clone https://github.com/ahpah-dev/Lunar-CLI.git cd Lunar-CLI
2

Run Diagnostic Matrix

Verify your local environment, Node runtime, and model connectivity:

node lunar.mjs doctor
3

Start Coding in Orbit

Launch the interactive REPL in any repository:

node lunar.mjs "Refactor auth and add unit tests"

⌨️

Lunar CLI Keyboard & REPL Shortcuts

REPL Escape Sequences

@<filepath>
Attach full file contents directly into the prompt context
!<cmd>
Escape to host shell to run immediate bash/powershell command

Slash Commands

/mode <ask|auto|plan|yolo>
Switch agent execution shield & tool approval mode
/model <name>
Switch active LLM model or OpenRouter/Ollama endpoint
/undo
Revert previous file write or surgical edit from backup snapshot
/doctor
Run full connectivity, provider health, and environment diagnostics

Approval Modals

y / Enter
Approve file modification or bash command execution
n / Esc
Deny action and return control back to conversational agent
a
YOLO mode: approve this and all subsequent actions automatically
e
Request agent to explain why this specific change is necessary
